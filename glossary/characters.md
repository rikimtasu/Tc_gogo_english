# Twinkle☆Crusaders GoGo! (PSP): Character Name Glossary

- **Rebuilt from:** Extracted scenario script in `gt_input/` (931 JSON files, 97,274 ordered entries, 83,452 speaker-tagged lines, 116 unique `name` labels; `1,982,446` Japanese characters).
- **Cross-referenced with:** VNDB [v666 / chars](https://vndb.org/v666/chars#chars) (`glossary/source/vndb_v666_chars.json`, 28 entries) and internal `EBOOT` asset IDs (`work/eboot/EBOOT_decrypted.bin`).
- **Counts explained:** **Speaker** = exact `name` field count in `gt_input/*.json`. **Msg** = exact substring occurrences in `message` fields across `gt_input/*.json`.
- **Status:** **LOCKED (Core Cast & Script Speaker Labels).** Every one of the 116 unique `name` labels in `gt_input/` is mapped below.

**Locked Conventions:**
- **Name order:** Given-name-first order in English prose and dialogue (e.g., *Synn Sakura*, *Nanaka Yuugiri*, *Eddie Mukaibara*).
- **Honorifics:** Retain original Japanese honorifics (`-san`, `-senpai`, `-sensei`, `-chan`, `-kun`, `-sama`, `-dono`, Akane's Kyoto `-han` / `Kaichou-han`, and Pasta's cat-speech `-nyama`).
- **Romanization:** Modified Hepburn with doubled vowels (`Yuugiri`, `Kujou`, `Tooyama`, `Satou`) rather than macrons, matching VNDB.
- **Spelling priority:** Locked project decisions and in-game/merchandise/EBOOT spellings override phonetic guesses (`ＳＡＫＵＲＡＳＹＮＮ` → *Synn*, `LOLOTTE` + German root → *Lolotte Rosenkreuz*, `BE_AS_PAQY` / goods → *Paqy*, goods / consensus → *Macaron*, `BE_EX_ARDEN` → *Arden*, `BE_EX_EAUDEROURKE` → *Eauderourke*).
